## 4) Выполнение улучшенного промпта (демо без исходного кода)

Так как исходный код Power Query не предоставлен, ниже — **демонстрационный результат**. Замените M‑код на ваш, чтобы получить точный Python.

### Переписанный промпт (краткая версия)
Преобразуй следующий Power Query (M) код в Python, сохранив логику трансформаций и типизацию данных. Используй pandas, добавь подробные комментарии на русском языке, логгирование из 5–10 строк и пример использования. Если информации недостаточно — задай уточняющие вопросы.

### Пример кода (шаблон)
```python
import logging
from typing import Optional

import pandas as pd


def transform_data(df: pd.DataFrame) -> pd.DataFrame:
    """
    Основная функция трансформации данных.
    В реальной задаче здесь повторяются шаги Power Query по порядку.
    """
    # 1. Приведение типов и очистка данных
    df = df.copy()
    df["date"] = pd.to_datetime(df["date"], errors="coerce")
    df["amount"] = pd.to_numeric(df["amount"], errors="coerce").fillna(0)

    # 2. Фильтрация строк по бизнес-условию
    df = df[df["amount"] > 0]

    # 3. Добавление вычисляемого столбца
    df["amount_with_tax"] = df["amount"] * 1.2

    return df


def configure_logging(level: int = logging.INFO) -> None:
    """Настройка логгирования с лаконичными, но информативными сообщениями."""
    logging.basicConfig(
        level=level,
        format="%(asctime)s | %(levelname)s | %(message)s",
    )


def main(input_path: str, output_path: str, sheet_name: Optional[str] = None) -> None:
    """Точка входа: загрузка данных, трансформация и сохранение результата."""
    configure_logging()

    logging.info("Старт процесса: чтение данных.")
    df = pd.read_excel(input_path, sheet_name=sheet_name)

    logging.info("Начата трансформация данных.")
    result = transform_data(df)

    logging.info("Сохранение результата.")
    result.to_excel(output_path, index=False)

    logging.info("Готово. Успешное завершение.")


if __name__ == "__main__":
    # Пример запуска
    main("input.xlsx", "output.xlsx")
```

### Описание работы (кратко)
1. **Загрузка данных:** читаем Excel в DataFrame.
2. **Трансформация:** повторяем шаги Power Query: типы, фильтрация, вычисления.
3. **Сохранение:** записываем результат в Excel.
4. **Логгирование:** фиксируем ключевые этапы процесса.

### Пример использования
**Вход:** Excel с колонками `date`, `amount`.  
**Выход:** Excel с фильтрованными строками и новым столбцом `amount_with_tax`.
